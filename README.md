# excel-sales-analysis
Sales data analysis and interactive dashboard built using Microsoft Excel.
Project Overview

This project analyses sales data to identify trends, evaluate business performance, and generate insights that can support better decision-making.

**Tools Used**

-Microsoft Excel / Google Sheets

-Pivot Tables

-Charts and Visualisations

-Formulas: SUMIFS, COUNTIFS, IF

-Interactive Slicers

**Project Objectives**

-Analyse overall sales performance.

-Identify top-performing products or categories.

-Compare sales across different periods or categories.

-Calculate key metrics, including average transaction value.

-Create an interactive dashboard to explore the data.

**Key Features**

-Pivot tables summarising sales data.

-Charts presenting important sales trends.

-Interactive slicers for filtering results.

-Formulas used to calculate key performance indicators (KPIs).

**Key findings**

-Recorded total revenue of R868.00 and total profit of R596.20.

-Merchandise contributed R324.00, or 37.3% of total revenue.

-Coffee Tumblers generated R324.00 in revenue, the highest among the listed products.

-Downtown recorded the highest store-location revenue at R270.00.


**Key Learnings**

This project strengthened my skills in data cleaning, spreadsheet formulas, data analysis, visualisation, and presenting findings in an accessible format
